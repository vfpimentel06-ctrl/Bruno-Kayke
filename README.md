# Bruno Kayke Tattoo — Site Portfólio

Site portfólio profissional para o tatuador **Bruno Kayke**, especialista em realismo preto e cinza, Barueri/Alphaville - SP.

## Como usar

Abra o arquivo `index.html` no navegador.

## Personalização

- **Portfólio**: Adicione fotos em `assets/images/portfolio/` e atualize o HTML
- **Textos**: Edite diretamente o `index.html`
- **Cores**: Ajuste as variáveis CSS em `css/style.css`

## Deploy gratuito

- [Netlify](https://netlify.com) — arraste a pasta
- [Vercel](https://vercel.com) — importe o repo
- GitHub Pages — ative nas configurações
